# GymOps

Система управления сетью фитнес-клубов: клиенты, абонементы, продажи, посещения,
расписание и отчётность.

Проект в разработке. Текущий релиз — v0.1: рабочее место администратора
ресепшена и сводка для владельца.

## Стек

Python 3.14 · Django 6.1 · PostgreSQL 17 · psycopg 3 · uv

Обоснование каждого выбора — в [ADR-0001](docs/decisions/0001-stack.md).

## Требования

- [uv](https://docs.astral.sh/uv/) — управление окружением и зависимостями.
  Версию Python устанавливать отдельно не нужно: uv поставит ту, что указана
  в `.python-version`

## Запуск окружения

```bash
git clone https://github.com/decemlabs/GymOps.git
cd GymOps
uv sync
```

`uv sync` создаёт виртуальное окружение и ставит зависимости **строго тех
версий, что записаны в `uv.lock`** — одинаково на любой машине и в CI.

Проверка:

```bash
uv run python -c "import django; print(django.get_version())"
```

Ожидаемый вывод — `6.1`.

Команды в окружении запускаются через `uv run`, активировать его вручную не
требуется.
